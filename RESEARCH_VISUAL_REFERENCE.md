## 🎨 Shader Generation Command Examples

### Example 1: Soul Prison Background
```
PROMPT INPUT:
{
  task: "generate_shader",
  style_guidelines: {
    art_style: "dark_surrealist_horror",
    color_palette: ["#2E004F", "#FF007F", "#8B0000"],
    effect: "twisted_earth_with_rim_lighting"
  },
  shader_type: "fragment"
}

EXPECTED OUTPUT:
- Perlin noise distorted earth
- Rim light at 45° angle
- Color blend: purple → dark red
- GPU load: <3ms
```

### Example 2: Zombie White House
```
PROMPT INPUT:

  task: "generate_shader",
```

## 📚 Visual Design Principles (Checklist)

### Liam Cobb's House Style
- [x] Every graphic element has smooth straight lines
- [x] All corners have same diameter
- [x] Maintain navigable space (characters move naturally)
- [x] Logical geometry despite surrealism
- [x] Background complexity serves foreground
- [x] Simplify busy compositions

### Thematic Integration
- [x] Background mirrors dialogue topic
- [x] Symbolism rewards viewer attention
- [x] Metaphors are visual, not narrated
- [x] Emotional tone matches conversation
- [x] Color carries psychological weight
- [x] Pacing reflected in environment density

### Quality Gates
- [x] Color accuracy (hex verification)
- [x] Navigability (character movement test)
- [x] Performance (GPU profiling <5ms)
- [x] Symbolism (thematic mapping confirmed)
- [x] Consistency (house style adherence)
- [x] Asset optimization (compression verified)
