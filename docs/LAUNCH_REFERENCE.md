## ⚠️ TROUBLESHOOTING

### If Production Build Fails
```bash
# 1. Clear build artifacts
rm -rf dist node_modules

# 2. Reinstall
npm install --legacy-peer-deps

# 3. Try building locally first
npm run build

# 4. If that succeeds, deploy again
vercel --prod
```

### If App Shows Blank White Screen
- Open DevTools (F12)
- Check Console tab for errors
- Check Network tab for failed requests
- Verify environment variables in Vercel
- Check that Canvas is rendering

### If Performance is Slow
- Open DevTools Performance tab
- Record and analyze
- Check FPS indicator
- Verify post-processing isn't disabled
- Check for console warnings

### If Analytics Doesn't Show Data
- Wait 24-48 hours (data may be delayed)
- Verify GA4 property ID is correct
- Check that tracking events fire in console
- Review Google Analytics dashboard settings
