How should the dialogues manifest in the 3D space?

Consider the immersive, psychedelic 'Midnight Gospel' aesthetic.

A

Floating 3D Text

Dialogue renders as physical 3D text geometry. Colors change based on mood intensity, and the words float dynamically past the camera.

B

Abstract HTML Bubbles

2D HTML overlays pinned to 3D coordinates. They glitch, warp, and pulse using CSS based on the mood metrics (intensity & colorTarget).

C

Environmental Sync

Minimal text subtitles. Instead, the entire 3D environment pulses, changes color, and alters animation speed in sync with the current dialogue node's mood.
