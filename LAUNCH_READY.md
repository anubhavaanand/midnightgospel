## 📞 Support & Troubleshooting

### Common Issues & Solutions

**App not loading?**
- Clear browser cache
- Check browser console for errors
- Verify internet connection
- Try incognito mode

**Low FPS on mobile?**
- Adaptive quality automatically reduces visual fidelity
- Disable post-processing for older devices
- Reduce particle counts

**Audio not playing?**
- Check browser audio permissions
- Verify audio files are loaded
- Check system volume

**Shader not rendering?**
- Verify WebGL 2.0 support
- Check browser dev console for shader errors
- Ensure proper shader syntax
